# 途记 · photo（微信小程序）

照片编辑小程序端，与安卓端（F:/ruanjian/photo）依据同一套「暗房修图台」设计规范实现。

## 页面

- **图库（pages/home）**：新建编辑（相册选图）、继续编辑卡片、3 列照片网格
- **编辑器（pages/editor）**：照片画布 + 底部常驻横向工具栏（调色/滤镜/水印/边框/裁剪/文字），点击工具后功能面板从工具栏上方滑出，面板首行为该功能的二级功能 chips
  - 调色/滤镜通过 CSS filter 实时生效
  - 水印 3×3 位置九宫格 + 不透明度
  - 边框 5 样式（无边框/白边/黑边/圆角/拍立得）
  - 裁剪比例 chips + 旋转
  - 文字字体/大小
- **模板（pages/templates）**：分类 chips + 模板卡网格 + 主题外观横向选择列表

## 主题系统

暗房黑 / 晨光白 / 胶片暖 / 青野 / 墨玉灰，5 套主题通过 CSS 变量（app.wxss）全局生效，选择持久化到本地存储，与安卓端 ThemeController 行为一致。
